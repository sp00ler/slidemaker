## Задачи → агенты → очередь

Роли: **Fable (Claude) = архитектор/ревью/коммит**. Исполнители работают до `npm run build` + `npm run typecheck` + `npm test` зелёные, БЕЗ коммита. Ревью и коммит — архитектор. Деплой — владелец вручную (VPS порт 3001, pm2 `slidemaker`, npm).

### Волна 1 — параллельно (файлы не пересекаются)

**T1. Opus 4.8 — рендер колоды (`lib/pptx.ts`)** — замечания 1, 2, 3
- Fit-contain для diagram/image: читать размеры PNG (сигнатура IHDR), вписывать в регион с сохранением аспекта, центрировать; подпись — ПОД регионом, никогда не поверх.
- Для diagram просить landscape: если Mermaid-граф вертикальный и узлов >5 — направление `LR` (проброс требования в prompt — координация с T2).
- Вариативность content-лейаутов: минимум 3 детерминированных варианта (полоса сверху / вертикальная полоса слева / акцент-блок под заголовком), ротация по индексу слайда, чтобы соседние отличались.
- Section-слайд: убрать 100% заливку accent — светлый фон + крупный accent-элемент (полоса/номер), заголовок без разреженного трекинга.
- Заодно: `FFFFFFCC` (8-hex, строка ~124) → `FFFFFF` + transparency (известный долг).
- Регресс-тест: расширить `lib/__tests__/pptx.test.ts` (аспект не искажается, лейауты чередуются).

**T2. Sonnet 5 — промпты и визуалы (`lib/anthropic.ts`, `lib/visuals.ts`)** — замечания 4, частично 2
- image_prompt: жёсткие константы стиля — светлый фон, flat/minimal editorial иллюстрация, палитра слайда (hex прокинуть), без фотореализма и тёмных сцен.
- Сместить выбор типа визуала: photo/chart/diagram предпочтительнее image; image — только когда остальное не подходит.
- Mermaid: требование «direction LR при >5 узлов», лимит узлов, короткие подписи узлов (<4 слов).
- Палитра: запрет насыщенного accent как полноэкранного фона; разнообразие палитр между заказами (не один синий).
- Текст: плотнее фактура (цифры, конкретика), меньше воды — вторая жалоба владельца сюда же.

**T3. Codex — таблицы из docx (`lib/docx.ts`)** — замечание 6
- Парсить `w:tbl`/`w:tr`/`w:tc` до общего стрипа тегов: таблица → markdown-таблица в text (строки `| a | b |`).
- Лимиты: максимум N таблиц, максимум строк/ячеек, вписаться в существующий `maxTextChars`.
- Тесты в `lib/__tests__/docx.test.ts`: docx с таблицей → markdown в тексте, порядок с абзацами сохранён.

### Волна 2 — после мержа волны 1 (общие файлы: page.tsx, checkout, anthropic.ts, pptx.ts)

**T4. Codex — поля «шрифт» и «цвета» в заказе** — замечания 7, 8
- Форма (`app/page.tsx`): опциональные «Шрифт» (select: Times New Roman, Arial, Calibri, «на выбор ИИ») и «Фирменные цвета» (до 2 hex, текстовое поле с валидацией).
- Проброс: checkout-validation → orders (колонки/JSON) → generate → anthropic (палитра: пользовательские hex приоритетнее) → pptx (fontFace всюду).
- Миграция `006_order_prefs.sql` (или JSON-колонка `prefs`).
- Тесты: валидация hex, fontFace в pptx, палитра переопределяется.

### Волна 3 — после волны 2 (лендинг)

**T5. Sonnet 5 — превью стилей + примеры работ** — замечания 9, 10, 5 (UX)
- Карточки стилей: мини-превью слайда (CSS-мокап: заголовок+буллеты+полоса в стилистике) вместо голой иконки.
- Секция «Примеры» на лендинге: 3–4 реальных экспортированных слайда (PNG от владельца, плохой `public/examples/2.png` заменить).
- Загрузка .docx — акцентировать как главный путь качества: «Загрузите работу — текст и картинки возьмём из неё» до поля темы.
- Перед редиректом на оплату: строка «Откроется тестовая страница ЮKassa — деньги не списываются» (пока тестовый режим).

### QA после каждой волны

**T6. Haiku — критик**: сгенерировать тестовую колоду (та же тема «источники земельного права»), скрины слайдов, чек-лист: диаграмма читаема без зума? лейауты соседних слайдов различаются? section-слайд не вырвиглазный? картинка по теме и светлая? Оценка ≥8/10 — волна принята.

## Очередь исполнения

1. **Opus 4.8** (T1, pptx-рендер) + **Sonnet 5** (T2, промпты) + **Codex** (T3, таблицы) — параллельно.
2. **Haiku** (T6) — QA волны 1 → **Fable** ревью+коммит.
3. **Codex** (T4, шрифт/цвета) → **Haiku** QA → **Fable** ревью+коммит.
4. **Sonnet 5** (T5, лендинг) → **Haiku** QA → **Fable** ревью+коммит.
5. Деплой владельцем после каждого мержа: `git pull && npm install && [psql миграция если есть] && npm run build && pm2 restart slidemaker --update-env`.

- Замечание 5 «текст не по файлу» полностью закрывается только загрузкой работы — по теме генерация останется приблизительной. Честно писать это в UI.
- Портфолио авторского тарифа — нужны реальные работы от владельца, кодом не решается.
